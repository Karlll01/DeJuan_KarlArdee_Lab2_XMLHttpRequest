1. What is the difference between readyState and status in XMLHttpRequest?

readyState tells the current stage of the XMLHttpRequest process.
It has different values from 0 to 4, where 4 means the request is complete.
Status tells the HTTP response status from the server.

For example, status 200 means the request was successful.


2. How can you make the request asynchronous?

You can make the request asynchronous by setting the third parameter of xhr.open() to true.

Example:
xhr.open("GET", "https://jsonplaceholder.typicode.com/posts/1", true);
The true value makes the request asynchronous.


3. Why is asynchronous communication recommended for web applications?

Asynchronous communication is recommended because it allows the webpage to continue working while waiting for the server response. 
It prevents the page from freezing or becoming unresponsive and provides a better user experience.
